# Gesture Synth Fork

A customized fork of **Gesture Synth**, focused on making the instrument simpler and more practical for guitarists and musicians who already have their own preferred chord shapes.

This fork keeps the core gesture-based idea of the original project while changing parts of the interface, controls, chord system, and playing experience.

## 🎸 Why This Fork?

The goal of this fork is to make Gesture Synth more comfortable for players who:

- Prefer familiar open-chord shapes.
- Already use a capo and want to transpose without changing their physical chord shapes.
- Don't need the original left-hand tilt functionality.
- Want a simpler interface with fewer controls.
- Want direct control over the pitch/transposition of the entire instrument.

## ✨ Changes in This Fork

### Removed Left-Hand Tilt Feature

The original Gesture Synth includes a left-hand tilt feature.

I removed the left-hand tilt functionality from this fork so the left hand can focus on selecting and playing chords without requiring an additional tilt gesture.

### 🎵 Added Pitch / Transpose Control

A **Pitch** control has been added to the main interface.

It allows the entire instrument to be shifted by semitones, from the current pitch through **12 half-steps**.

This is particularly useful for guitarists who are comfortable playing a particular open-chord shape or using a capo.

For example, if you are comfortable playing a progression using familiar open shapes but need the song in another key, you can keep the same physical chord shapes and use the **Pitch** control to transpose the instrument.

The displayed scale and chord information update along with the pitch.

### 🎸 Custom Chords

The custom chord boxes allow you to define the chords you want to use.

The default progression in this fork is:

**Am · G · F · E · Dm · C · Em**

The first custom chord also determines the displayed scale root and type.

For example:

- `Am` → **Scale: A minor**
- `G` → **Scale: G major**
- `C` → **Scale: C major**
- `Dm` → **Scale: D minor**

Changing the pitch also transposes the displayed scale.

### 🎨 Redesigned Interface

The interface has been simplified and redesigned with:


- Compact scale indicator
- Simplified chord controls
- Simplified settings
- Removed unnecessary menu options
- Custom chord configuration
- Pitch/transposition control


## 🎼 Designed With Guitarists in Mind

One of the main reasons for adding the pitch control is to make the instrument more flexible for guitar players.

If you have a set of open chords that you are comfortable playing, or you normally use a capo to change the key, the pitch control lets you transpose the instrument while keeping your familiar chord shapes.

This means you can focus on playing rather than constantly adapting to a new set of chord shapes.
